# 皮肤

- **没说皮肤 = 西瓜原皮**（红背带、白T、西瓜包、西瓜髻+藤）。不要每次强调「必须原皮」。
- 用户指定皮肤就用指定的。
- 用户让生成皮肤：出新设定图，存进 `public/refs/` 和 `assets/masters/`，以后这套都锁这张。
- 设定图已经有：`public/refs/watermelon-white.jpg`（原皮）、`public/refs/duomei-master-sheet.jpg`。

# 强制流程（跳过 = 不许交付）

1. 看实物，学**做法**。不抄别人的 gag 和构图。
2. 写出方案。没让改的表情禁止重做。
3. **一板多张**静帧，打分过了才做 **6 秒** 视频。
4. **视频检查**：动作合理。不对就重生成。分身、多手、脸漂 = 打回。
5. **视频转 GIF**：ffmpeg 整段转。取 **约 3 秒** 完整动作，**30fps**。禁止抽成几张静帧。
6. **GIF 再查**：时长约 3 秒，封面 = 第一帧，格子能看懂。
7. 飞踢必须把猪踢飞，不能站着挨踢。

及格线：
- 成品约 3 秒、30fps
- 默认原皮；指定了皮肤就换
- 标题 = 画面动作
- 打人要生气，禁止微笑打人
